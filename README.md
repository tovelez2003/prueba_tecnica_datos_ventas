# Extraccion datos ventas
Este codigo es una extraccion del archivo de excel datos_ventas.xlsx
en el cual se aplica filtros , limpieza de datos y formateo de tipo de variables para resolver ciertas preguntas de negocio

# como salida genera un excel  (resumen_ventas.xlsx) con dos hojas:
"Resumen_Ventas": Contiene el total de ventas por vendedor.
"Ventas_Mensuales": Contiene el total de ventas por mes.

# para ejecutar el codigo se tiene el archivo requeriments 

	pandas 
	openpyxl
